# Mine wall deposits: supply and balance

The ordinary order remains 100 matching mined blocks in the last verified live
configuration. Deposits supply only the deficit: remaining quota minus exposed
matching blocks with an ore neighbour minus pending regeneration. Isolated
pre-existing ore remains mineable but does not suppress visible deposits. One pass adds at most 16 connected
blocks; no drops, XP, vault, tokens or completion rewards are granted by placement.
Existing per-break drops, tools, enchantments, quotas and completion grants are unchanged.

Before: finding existing scattered ore and independent weighted regeneration.
After: connected exposed deposits also replace supported decorative full blocks.
Placement is persistent managed mine regeneration, journaled before mutation.
It does not reset the entire cave or touch functional blocks. Indexed hosts and
loaded chunks bound the supply. Idle/incident states do not generate deposits.

For equal action counts, item and XP output are unchanged. Faster discovery can
increase actions/hour; low/base/high sensitivity assumes 1/2/4 orders per active
hour before and 2/4/8 after, one hour/day and 10/25/50 participants. These are
assumptions, not measurements or promised throughput. With the inventory's
220 XP + 4 iron/order, XP/day is 220/440/880 before and 440/880/1760 after;
iron/day is 4/8/16 before and 8/16/32 after. Raw mined drops are separate and
vary by tool/ore; there is no additional roll during placement. Direct vault
and tokens remain zero. SELL is not assumed disabled: existing shop conversion,
EcoJobs eligible events and contract budgets can monetize faster resource input;
no new conversion, price, permission or bypass is introduced here. Future
SELL-off is a separate scenario, not current zero indirect income.

This is an owner-requested availability improvement, not a reward-rate increase.
Unknown actual actions/hour and enchantment mixes prevent a measured monetary
forecast. Keep existing caps and verify actual throughput after activation before
any further supply increase. Do not sum resource sale value with raw items as
if both were independent rewards.

The 2026-09-11 full-map correction does not change those values or caps. It makes
the startup reindex run for a persisted active basic-mine order, restricts mining
to the current order's declared ore materials, and recognizes additional exposed
full-block cave decoration such as deepslate/stone/tuff/mud bricks, moss/rooted
dirt and bone blocks. A read-only scan of the live `mine1` cuboid found 3,317,760
positions, 160,736 non-air blocks adjacent to air and 142,854 eligible exposed
hosts under the conservative masonry/terrain policy before adding the smaller
moss/dirt/bone families. Deposits remain deficit-bound and limited to 16 connected
blocks per pass. Direct delta remains 0 vault, 0 tokens, 0 XP and 0 granted items;
the same unmeasured throughput sensitivity above remains the indirect risk model.
