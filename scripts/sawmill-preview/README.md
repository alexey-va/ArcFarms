# Круговая пилорама — интерактивное превью

Локальный макет для существующего цеха в `rc_atelier_cedar_sawmill` около
`191 73 182`. Здание взято из чтения живого мира 25 октября 2026 года;
снимок содержит только блоки и их состояния, без данных игроков.
Механизм расположен в `[188.5, 73, 180.5]` и подаёт бревно вдоль `+Z`.

Одна круговая пила выступает через стол снизу. Каретка проводит закреплённое
бревно через диск; один горбыль остаётся на выходном столе. Бревно сохраняет
спиленную грань, отводится от диска и возвращается назад. Один проход занимает
25 секунд. Сцена начинается в покое: нажмите на рычаг станка, чтобы запустить
или приостановить движение. После завершения рычаг запускает повтор макета.
Поворот камеры перетаскиванием не должен нажимать рычаг.

## Сборка и проверка

Из корня ArcFarms:

```sh
node scripts/sawmill-preview/check.mjs
node scripts/sawmill-preview/build.mjs
python3 -m http.server 8847 --bind 127.0.0.1 --directory build/reports/sawmill-preview
```

Откройте `http://127.0.0.1:8847/?view=operator`. Для одинакового статичного
сравнения используйте `?view=operator&t=10&paused=1`. В интерфейсе доступны
ракурсы, пауза, временная шкала, скорость, опилки и исходный интерьер.

Сборщик использует соседний `ruscrafting-ops/scripts/location-atelier` и
проверенный клиентский JAR Minecraft 1.21.11 из локального кеша. Пути можно
задать явно: `--atelier=/path/to/location-atelier`, `--client-jar=/path/to/client.jar`,
`--out=/path/to/output`. HTML включает геометрию и текстуры; сервер импорта
не запускается, `.schem` после сборки удаляется.

## Редактирование

- `machine.mjs` — станина, диск, привод, каретка, опоры и камеры.
- `motion.mjs` — единый таймлайн, положение заготовки и сохранённый распил.
- `preview.js`, `preview.css` — визуализация, деревянные детали и 3D-рычаг.
- `room.snapshot.json` — очищенный снимок помещения с точными состояниями блоков.
- `check.mjs` — опоры и высоты, непрерывность распила, регрессия совпадающих граней.

`preview-mask.json` в результате сборки перечисляет интерьерные детали,
скрытые только в браузере. Переключатель исходного интерьера восстанавливает
их в макете. Постройка и механизмы на сервере этим кодом не меняются.

Это авторский макет, а не экспорт работающего Bukkit-механизма. Станок
использует материалы и модели Minecraft; восьмигранное бревно и цельные шкивы
имеют отдельную текстурированную геометрию превью. Для реализации в игре
понадобится соответствующая модель или Display-геометрия. Нативный клиент,
звук, пакетная интерполяция и нагрузка здесь не проверяются.
